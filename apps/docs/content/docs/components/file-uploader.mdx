## Default

Files dropped or browsed into `FileUploader.Dropzone` appear in `FileUploader.List` with an icon or image preview, name, size, and a remove button.

<ComponentPreview name="file-uploader-default" />

## Thumbnail preview

`FileUploader.Thumbnails` displays the selected files as square thumbnails with a corner remove button.

<ComponentPreview name="file-uploader-thumbnail" />

## Avatar

`variant="avatar"` turns the dropzone into a circular uploader that fills with the selected image; hovering it reveals the message overlay again.

<ComponentPreview name="file-uploader-avatar" />

## FileDropBox

The `dropbox` layout places a box-style dropzone (`variant="box"`) inline with the thumbnails.

<ComponentPreview name="file-uploader-dropbox" />

## Single file

`maxFiles={1}` makes the uploader single-file: a new selection replaces the previous one.

<ComponentPreview name="file-uploader-single" />

## Validation

`accept`, `maxSize`, `minSize`, and a custom `validator` reject files declaratively; rejections style the dropzone through `[data-drag-reject]` and surface details in `onDropRejected`.

<ComponentPreview name="file-uploader-validation" />

## API Reference

Built on [react-dropzone](https://react-dropzone.js.org). The root is a headless provider — every react-dropzone option passes through it — and the parts carry Hummingbird's `file-uploader-*` classes. The uploader manages file selection only; uploading the files is left to the application.

## Styling

The file uploader component utilizes several CSS variables for customization, defined on the dropzone and preview classes.

```css
.file-uploader {
  --file-uploader-padding: --spacing(6);
  --file-uploader-bg: var(--background-color-subtle);
  --file-uploader-border-color: var(--border-color-default);
  --file-uploader-border-radius: var(--radius-xl);
  --file-uploader-hover-border-color: var(--color-primary);
  --file-uploader-hover-bg: --alpha(var(--color-primary) / 5%);
  --file-uploader-reject-border-color: var(--color-danger);
  --file-uploader-reject-bg: --alpha(var(--color-danger) / 5%);
  --file-uploader-avatar-overlay: --alpha(var(--color-inverse) / 70%);
  --file-uploader-avatar-size: --spacing(40);
}
.file-uploader-list {
  --file-uploader-list-padding: --spacing(2);
  --file-uploader-list-font-size: var(--text-sm);
  --file-uploader-list-bg: var(--background-color-subtle);
  --file-uploader-list-border-radius: var(--radius-lg);
  --file-uploader-list-image-size: --spacing(13);
  --file-uploader-list-image-border-width: var(--border-width);
  --file-uploader-list-image-border-color: var(--border-color-subtle);
  --file-uploader-list-image-border-radius: var(--radius-lg);
}
.file-uploader-thumbnails {
  --file-uploader-thumbnail-size: --spacing(14);
  --file-uploader-thumbnail-border-width: var(--border-width);
  --file-uploader-thumbnail-border-color: var(--border-color-subtle);

}
```
