---
title: Loader
description: A visual indicator for loading states, with border and growing spinners and an animated bar loader.
---

## Default

The default loader is a circular border spinner. It renders `role="status"` with a visually hidden label for screen readers.

<ComponentPreview name="loader-default" className="text-center" />

## Colors

The `color` prop tints the spinner; without it the spinner inherits `currentcolor`.

<ComponentPreview name="loader-colors" />

## Growing spinner

`variant="grow"` renders a pulsing indicator that grows and fades.

<ComponentPreview name="loader-grow" />

## Sizes

`size="sm"` renders a small spinner; any other dimension is set with a size utility.

<ComponentPreview name="loader-sizes" />

## Bar loader

`variant="bar"` renders a horizontal indeterminate loading bar. The `color` prop switches the bar's color scheme.

<ComponentPreview name="loader-bar" />

## Buttons

A small loader inside a disabled button indicates a busy action. The loader is hidden from screen readers there, since the button provides the label.

<ComponentPreview name="loader-buttons" />

## Styling

Hummingbird React loader is styled entirely through Hummingbird's utility classes and CSS
variables.

- See the full list of available loader classes in the [Class overview](https://hbui.dev/docs/components/loaders/#class-overview).
- Visit the [CSS Variables](https://hbui.dev/docs/components/loaders/#css-variables) documentation to explore all available variables.
