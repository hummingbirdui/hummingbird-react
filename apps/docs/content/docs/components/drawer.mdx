title: Drawer
description: A draggable, dismissible panel that slides in from any edge of the screen.

## Default

<ComponentPreview name="drawer-default" className="text-center" />

## Direction

Passing `direction` (`"top" | "right" | "bottom" | "left"`) to `Drawer` sets the edge the panel slides from.

<ComponentPreview name="drawer-direction" />

## Without overlay

Setting `overlay={false}` on `Drawer.Content` renders the panel without the backdrop.

<ComponentPreview name="drawer-without-overlay" className="text-center" />

## Scrollable body

`Drawer.Body` grows to fill the panel and scrolls its own overflow while the header stays pinned.

<ComponentPreview name="drawer-scrollable" className="text-center" />

## API Reference

Built on [Vaul](https://vaul.emilkowal.ski/). Each part forwards all props to its Vaul counterpart, except `Drawer.Header` and `Drawer.Body`, which are Hummingbird-specific layout parts rendered as plain `div` elements.

### Drawer.Portal

When used, portals your overlay and content parts into the `body`. `Drawer.Content` renders this part automatically, so you rarely need to use it directly.

## Styling

Hummingbird React drawer is styled entirely through Hummingbird's utility classes and CSS
variables.

- See the full list of available drawer classes in the [Class overview](https://hbui.dev/docs/components/offcanvas/#class-overview).
- Visit the [CSS Variables](https://hbui.dev/docs/components/offcanvas/#css-variables) documentation to explore all available variables.
