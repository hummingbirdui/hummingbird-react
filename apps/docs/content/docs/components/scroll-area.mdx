---
title: Scroll Area
description: A scrollable region with custom, consistently styled scrollbars that keep native scrolling behavior.
---

## Default

Content scrolls inside `ScrollArea.Viewport`; `ScrollArea.Scrollbar` renders a vertical scrollbar with a default thumb. With the default `type="hover"`, the scrollbar appears while hovering the area.

<ComponentPreview name="scroll-area-default" />

## Horizontal

`orientation="horizontal"` on the scrollbar handles horizontally overflowing content.

<ComponentPreview name="scroll-area-horizontal" />

## Both directions

Two scrollbars cover both axes, and `ScrollArea.Corner` fills the square where they meet.

<ComponentPreview name="scroll-area-both" />

## Rounded

The `rounded` prop gives the track and thumb the pill shape of Hummingbird's `scrollbar-rounded` utility.

<ComponentPreview name="scroll-area-rounded" />

## Always visible

`type="always"` keeps the scrollbar visible whenever content overflows, instead of showing it on hover.

<ComponentPreview name="scroll-area-always" />

## API Reference

Built on the [Radix UI Scroll Area](https://www.radix-ui.com/primitives/docs/components/scroll-area) primitive. Each part forwards all props to its Radix counterpart and carries its own Hummingbird utility class (`scroll-area`, `scroll-area-viewport`, `scroll-area-scrollbar`, `scroll-area-thumb`, `scroll-area-corner`).

## Styling

The scroll area component utilizes several CSS variables for customization, defined on the root's `scroll-area` class. Overriding them restyles the scrollbar size, track, and thumb.

```css
.scroll-area {
  --scroll-area-scrollbar-size: --spacing(3);
  --scroll-area-thumb-color: var(--background-color-emphasis);
  --scroll-area-track-color: var(--background-color-muted);
}
```
