## Styling

Hummingbird React skeleton is styled entirely through Hummingbird's utility classes and CSS variables.

- See the full list of available placeholder classes in the [Class overview](https://hbui.dev/docs/components/placeholders/#class-overview).
- Visit the [CSS Variables](https://hbui.dev/docs/components/placeholders/#css-variables) documentation to explore all available variables.
