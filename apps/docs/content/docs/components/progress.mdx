<ComponentPreview name="progress-default" className="max-w-sm mx-auto" />

## Colors

The `color` prop on `Progress.Bar` changes the bar's background.

<ComponentPreview name="progress-colors" />

## Height

The track height is adjusted with a height utility on the root.

<ComponentPreview name="progress-height" />

## Labels

Content inside `Progress.Bar` renders as a label on the bar.

<ComponentPreview name="progress-labels" />

## Multiple bars

`Progress.Stacked` combines several progress segments in one track; each segment is sized by its own `value`.

<ComponentPreview name="progress-stacked" />

## Striped

Setting `striped` overlays a striped pattern on the bar.

<ComponentPreview name="progress-striped" />

## Animated stripes

Combine `animated` with `striped` to animate the stripe pattern.

<ComponentPreview name="progress-animated" />

## API Reference

Built on the [Radix UI Progress](https://www.radix-ui.com/primitives/docs/components/progress) primitive. Each part forwards all props to its Radix counterpart.

## Styling

Hummingbird React progress is styled entirely through Hummingbird's utility classes and CSS
variables.

- See the full list of available progress classes in the [Class overview](https://hbui.dev/docs/components/progress/#class-overview).
- Visit the [CSS Variables](https://hbui.dev/docs/components/progress/#css-variables) documentation to explore all available variables.
