---
title: Navigation Menu
description: A collection of links and panels for navigating a website, with keyboard support and an animated, resizing viewport.
---

## Default

Each `NavigationMenu.Item` holds either a `NavigationMenu.Trigger` with its `NavigationMenu.Content` panel, or a single `NavigationMenu.Link`. Panels open on hover or click and share one viewport that resizes between them.

## With descriptions

A `NavigationMenu.Link` lays out its children in a column, so a title and a short description can sit inside one link.

## Without viewport

Setting `viewport={false}` renders each panel below its own item with its own surface instead of inside the shared viewport.

## API Reference

Built on the [Radix UI Navigation Menu](https://www.radix-ui.com/primitives/docs/components/navigation-menu) primitive. Each part forwards all props to its Radix counterpart.

## Styling

Hummingbird React navigation menu is styled through Hummingbird's utility classes and CSS variables. Triggers and top-level links reuse the `nav-link` class, and panels reuse the dropdown's surface tokens.

- The `navigation-menu`, `navigation-menu-list`, `navigation-menu-item`, `navigation-menu-trigger`, `navigation-menu-content`, `navigation-menu-viewport`, `navigation-menu-link` and `navigation-menu-indicator` classes ship with `@hummingbirdui/react`.
- The `navigation-menu` class defines the `--nav-link-*` variables for its triggers and the `--navigation-menu-*` variables (surface, spacing and link colors) for its panels.
- See the [Nav CSS Variables](https://hbui.dev/docs/components/navs-tabs/#css-variables) and [Dropdown CSS Variables](https://hbui.dev/docs/components/dropdown/#css-variables) documentation for the underlying tokens.
