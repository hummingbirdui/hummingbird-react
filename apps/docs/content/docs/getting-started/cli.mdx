## Create a project

`create-hummingbird-react-app` scaffolds a new project with Hummingbird React already configured. Run it with a preferred package manager.

<PackageManagerTabs command="npx create-hummingbird-react-app@latest" />

The CLI asks a few questions:

1. **Where to create the project.** The default is `my-hummingbird-app`.
2. **Which framework to use.** Next.js is preselected.
3. **Whether to install dependencies.** It uses the package manager that ran the command.
4. **Whether to initialize a git repository.** This is skipped inside an existing repository.

Then start the development server and open the URL it prints.

<PackageManagerTabs command="npm run dev" />

## What's included

All templates share the same setup:

- **Tailwind CSS v4** with the framework's official integration: the Vite plugin for Vite, Astro and React Router, and PostCSS for Next.js and Gatsby.
- **Hummingbird React styles** imported in the CSS entry. No Tailwind config is needed, because the package registers its own `@source` paths.
- **Class-based dark mode.** The saved theme is applied before first paint, so there is no flash of the wrong theme.

```css
@import "tailwindcss";
@import "@hummingbirdui/react";

@custom-variant dark (&:where(.dark, .dark *), .dark);
```

## Non-interactive use

Pass `--yes` to run without prompts, for example in CI or scripts. Without other options it creates `my-hummingbird-app` from the `nextjs` template, installs dependencies, and initializes git. A non-empty target directory is an error unless `--overwrite` is passed.

<PackageManagerTabs command="npx create-hummingbird-react-app@latest my-app --template astro --no-git --yes" />

## Requirements

The CLI needs Node.js 20.19 or later. Some frameworks need a newer version, and the CLI warns when the running version is outside the template's range.

- **Astro** needs Node.js 22.23.4 or later.
- **React Router** needs Node.js 22.22 or later.
- **Gatsby** supports Node.js versions below 26.

## Adding to an existing project

The CLI only creates new projects. To add Hummingbird React to an existing app, follow the [installation guide](/docs/getting-started/installation) or the [framework guide](/docs/getting-started/framework-guides) for the framework in use.
