---
title: Text
description: Text is a polymorphic typography component for rendering any text element with consistent size, weight, and overflow handling.
---

## Default

Text renders a `p` element by default.

<ComponentPreview name="text-default" />

## Headings

Text can render any heading element from `h1` to `h6`.

<ComponentPreview name="text-headings" />

## Elements

Other text elements can be rendered by passing the `as` prop.

<ComponentPreview name="text-elements" />

## Sizes

The `size` prop sets the font size, from `xs` up to `9xl`.

<ComponentPreview name="text-sizes" />

## Font weight

The `fontWeight` prop sets the font weight, from `thin` up to `black`.

<ComponentPreview name="text-weights" />

## Truncate

Setting `truncate` cuts off overflowing text on a single line with an ellipsis.

<ComponentPreview name="text-truncate" />

## Line clamp

The `lineClamp` prop limits the text to the given number of lines and truncates the overflow with an ellipsis.

<ComponentPreview name="text-line-clamp" />
